Claude Code 설치 가이드

Windows PowerShell — PowerShell 7 설치부터 Claude Code 로그인까지

프로님, 안녕하세요.

Claude Code를 회사 PC에서 PowerShell로 설치·사용하는 방법을 순서대로 정리해서 보내드립니다. 처음부터 그대로 따라 하시면 됩니다. 혹시 중간에 막히는 부분 있으면 편하게 말씀 주세요.

1

기존 PowerShell 열기

시작 메뉴에서 PowerShell을 검색해 파란 아이콘의 Windows PowerShell을 실행합니다. Windows에 원래 내장되어 있는 것이라 별도 설치 없이 바로 있습니다.

2

PowerShell 7 설치 여부 확인 및 설치

방금 연 창에 아래 명령을 입력해 winget이 동작하는지 확인합니다.

winget --version

버전 숫자(예: v1.29.290)가 뜨면 정상입니다. 이어서 PowerShell 7 설치를 시도합니다.

winget install --id Microsoft.PowerShell -e
이미 설치되어 있다면 "이미 설치된 기존 패키지를 찾았습니다" 메시지가 뜹니다 — 정상입니다. 이미 깔려 있다는 뜻이니 3단계로 넘어가시면 됩니다. 처음 설치하는 경우라면 다운로드·설치가 진행됩니다. 중간에 라이선스 동의를 물으면 Y를 입력합니다. 관리자 권한은 필요 없습니다.
winget 자체가 안 될 경우 아래 명령으로 설치 파일을 직접 받아서 설치할 수 있습니다. 
Invoke-WebRequest -Uri "https://github.com/PowerShell/PowerShell/releases/download/v7.6.5/PowerShell-7.6.5-win-x64.msi" -OutFile "$env:USERPROFILE\Downloads\PowerShell-7.6.5-win-x64.msi"
다운로드된 파일을 탐색기에서 더블클릭해 설치 마법사를 진행합니다. 회사 PC 정책상 관리자 권한을 요구하면 IT팀에 설치 요청이 필요합니다.
3

PowerShell 7로 전환

지금 창에서 그대로 아래 명령을 입력합니다.

pwsh

프롬프트가 바뀌면서 PowerShell 7 세션으로 들어갑니다. 버전을 확인해봅니다.

$PSVersionTable.PSVersion

Major 값이 7로 나오면 정상입니다.

다음부터는 시작 메뉴에서 PowerShell 7을 검색하면 검정 아이콘으로 바로 실행할 수 있습니다. 파란 아이콘 = 기존 5.1, 검정 아이콘 = 새로 설치한 7 — 이렇게 구분하시면 됩니다.
4

Claude Code 설치

PowerShell 7 세션(방금 바뀐 창)에서 아래 한 줄을 입력합니다.

irm https://claude.ai/install.ps1 | iex
  • 관리자 권한 필요 없음
  • Node.js 설치 필요 없음
  • 2분 이내 완료, 이후 자동으로 백그라운드 업데이트됨
5

설치 확인

claude --version

버전 번호(예: 2.1.211 (Claude Code))가 뜨면 설치 성공입니다.

6

실행 및 로그인

작업하실 폴더로 이동한 뒤 실행합니다.

cd C:\작업할\프로젝트\폴더
claude

브라우저가 자동으로 열리면서 로그인 화면이 뜹니다. 가지고 계신 Claude 계정(Pro / Max / Team / Enterprise / Console 중 하나 — 무료 claude.ai 플랜은 안 됩니다)으로 로그인하시면 됩니다.

사내망 프록시 때문에 브라우저 로그인 콜백이 안 될 경우, 터미널에 뜨는 인증 URL을 복사해서 브라우저에 직접 붙여넣고 진행하시면 됩니다.
7

기본 사용법

  • 그냥 자연어로 질문·지시하면 됩니다.
  • /help — 명령어 목록 확인
  • /init — 현재 프로젝트에 CLAUDE.md 생성 (프로젝트 컨텍스트 잡기용)
  • claude doctor — 뭔가 이상할 때 진단해주는 명령어, 문제 생기면 제일 먼저 이걸 돌려보시면 됩니다
  • 종료: exit 입력 또는 Ctrl+C 두 번
!

막히는 경우

설치나 로그인이 계속 안 되면, 사내 방화벽이 claude.ai, console.anthropic.com, api.anthropic.com 도메인을 막고 있을 가능성이 있습니다. 이 경우 IT팀에 방화벽 예외 요청을 하시면 됩니다.
